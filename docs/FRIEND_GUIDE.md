# Mori 双端体验包：安装与配置说明

整理日期：2026-10-02。Windows 4.7.0 / Android 4.7.0（36）。这是基于 Mori 修改的朋友体验版，仍在开发中。

## 1. 先从本地功能开始

安装后就可以体验链接解析、下载和灵感相册，不需要配置自己的云服务器。解析、下载需要联网；已下载的内容可以在本地查看。电脑端还可以使用完整策划画布。

本包没有附带任何个人同步密钥、账号登录状态、素材或相册数据。未配置密钥时，云同步按钮不可用，这是正常状态。推荐先用本地相册包把电脑相册及关联策划传到手机，无需服务器。

包内文件：

- Windows/Mori_4.7.0_x64-setup.exe：电脑安装程序。
- Android/Mori v4.7.0.apk：手机安装程序。
- 先读我.html：浏览器直接打开的排版说明。
- 安装与配置说明.txt：纯文字版，可在手机打开。
- 源码（可选）/Mori-体验版源码.zip：本次工作区对应的公开源码、构建配置及现存外部依赖；普通使用者不需要解压。
- LICENSE.txt：项目现有 GPL v3 许可文本。

## 2. Windows 安装

1. 使用 Windows 10/11 的 64 位 x64 电脑，先把分享包完整解压。
2. 双击 Windows 文件夹里的安装程序，按向导选择安装位置。
3. 从开始菜单或安装目录启动 Mori。界面空白或提示缺少 WebView2 时，安装微软提供的 Evergreen WebView2 Runtime，再重新打开。
4. 若界面不是中文，在 Settings / 设置中把 Language / 语言选成“中文（简体）”。下载目录按自己的需求选择，不要照搬其他电脑的路径。
5. 复制一条支持的作品链接，粘贴到 Mori，点击“解析”，再下载所需图片或视频。先用一条链接确认自己的网络和保存目录正常。

[微软 WebView2 官方下载](https://developer.microsoft.com/microsoft-edge/webview2/)

抖音部分作品需要登录。电脑端可以在“设置 → 网络与性能 → 抖音账号”打开 Mori 专用 Edge 登录窗口；完成登录并关闭这个窗口，再回 Mori 检查登录状态、重试解析。登录会话只保存在自己的电脑。

如果此前安装过其他来源的 Mori，先保存自己的重要内容；版本和签名不一定相同，不要为了安装而直接清空数据。

## 3. Android 安装

1. 手机系统需 Android 7.0 或以上。将 Android 文件夹中的 APK 发到手机，用系统文件管理器打开。
2. 按系统提示，仅为当前打开 APK 的应用允许“安装未知应用”，完成安装。首次打开时按下载需求授予照片、媒体等权限。
3. 复制作品链接，打开 Mori 粘贴并解析，再下载。解析页面的“服务器 1 / 服务器 2”是素材解析线路，不是相册同步服务器。
4. 如果提示应用签名冲突，先确认旧版来源并保留数据；不要直接卸载有重要内容的旧版。

手机相册的使用方式：进入灵感相册，点击封面打开相册；“分组”按来源横向看图，“画布”可单指平移、双指缩放。点击来源标题可以打开原作品；轻点图片进入全屏预览。已完成 AI 分析时，可上滑预览面板查看该图片的姿势、建议摄影参数和拍摄建议。右上角“＋”创建相册，“⋯ → 整理来源分组”把来源加入或移出当前相册。

“策划”打开当前相册关联的策划；本地相册没有策划时会自动创建可编辑的本地策划，并把当前相册图片加入画布。本地相册和本地相册包不再是只读预览。

## 4. 推荐：不配置服务器，使用本地相册包

1. 电脑进入“灵感相册”，选中要传到手机的相册。若已有策划，确认它关联的是这个相册。
2. 展开“本地相册包”，点击“导出当前相册包”。导出范围是所选相册的完整来源分组、图片、收藏帧、视频链接和关联策划，包含策划中另外插入的图片；不会把别的相册一起导出。
3. 完成后点击“打开文件夹”，找到 .mori-album 文件。通过 USB、微信文件或网盘把这个文件发送到手机。若聊天工具改了扩展名，先恢复 .mori-album；请发送原文件，不要发送截图。
4. 手机进入“灵感相册 → 右上角 ⋯ → 本地相册包 → 导入相册包”，用系统文件选择器选中它，等待导入完成。
5. 打开相册即可切换“分组 / 画布”查看图片；若包内包含策划，点击“策划”进入全屏预览。图片已保存到手机应用本地，之后可断网查看；打开原作品链接仍需要联网。

每次导入都会创建一个独立本地副本，旧相册保留，不会覆盖现有手机修改。电脑更新之后，重新导出并在手机导入新版即可。这是单向文件传递，不会自动双向合并；手机对本地策划的修改只保存在该手机副本中。

图片沿用最长边 2048、JPG 质量 0.88 的预览格式，原视频仅带链接，不带完整视频文件。单包上限 128 MB，超过时在电脑拆成几个相册再导出。源图丢失时停止导出；损坏文件或保存失败不会替换原有相册。空相册、没有策划的相册也可以传递。

无需配置同步密钥，不访问云端，也不占用 Cloudflare 的额度。电脑和手机都需要使用本体验版 4.7.0 或后续支持 .mori-album 的版本；原有仅策划的 .mori 文件属于另一种格式。

## 5. 可选：接入同步服务后，怎样配对

本节仅适用于服务维护者明确允许你访问的同步库。当前安装包的同步地址固定，不能只在设置中填写另一台服务器的地址来完成自建接入。

1. 向维护者取得该同步库的密钥。在电脑“设置 → Personal Sync → 个人同步密钥”粘贴，点击“保存到此设备”；保存后页面会重新载入。
2. 手机在同一位置保存同一个库的密钥。电脑“复制配对密钥”可用于自己两台设备配对，密钥不要放在公开聊天或分享包里。
3. 电脑进入相册，选中要同步的相册并准备好关联策划，点击“同步当前相册”，等待成功提示。一个相册会连同它关联的策划一起同步。
4. 手机进入相册页，打开“⋯ → 同步与恢复”，刷新云端列表，选择对应相册，点击“同步所选相册”，等待图片下载完成。
5. 下载后从手机相册封面进入；在同一相册内切换“相册 / 策划”，无需再单独下载一个策划。
6. 手机对该策划做了允许的调整后，点击“同步相册”；回电脑先同步接收手机修改，再继续编辑并上传。当前是手动同步，不会持续后台自动更新；最好避免两边同时编辑同一内容。

同步的是图片预览、视频链接、收藏帧及关联策划。图片按最长边 2048、JPG 质量 0.88 传输；电脑原图不被替换。原视频文件不会上传云端，手机需打开链接查看视频。请以成功提示和实际图片是否齐全判断完成，网络失败可以重试。

遇到“有尚未上传的手机修改”：先在手机打开对应相册或策划，点击同一个“同步相册”上传，再回电脑同步接收。没有单独的“上传修改页面”。

“按电脑重建”是旧数据恢复入口，会在确认并成功备份后替换所选组的手机内容。它不属于首次使用步骤；只有明确要以电脑该组为准、已处理手机独有内容时才使用。“导出旧内容备份”也不是日常同步必需操作。

## 6. 朋友能不能共用现有云服务器

可以共用同一个 Cloudflare 账号，无需朋友自己购买 VPS 或注册一个账号。但本版后台只有一个 MORI_SYNC_TOKEN；持有同一密钥的设备可以读取整个项目目录并修改该服务的数据。相册名称、客户端文件夹、R2 前缀本身都不是访问权限。

可选方式：

- 先体验本地功能：直接使用本包，不提供同步密钥，互不影响。
- 明确共用整个素材库：维护者自愿提供现有密钥，双方能访问同一云端库；不具备朋友专属空间。
- 同账号建立朋友独立服务（建议用于少量朋友）：独立 Worker、D1 数据库、R2 桶和密钥，双方数据分开；维护者负责托管，朋友只安装并配对。
- 朋友自己托管：在朋友自己的 Cloudflare 账号建立同样的独立资源，自己维护额度与密钥。

后两种需要客户端支持独立地址，或者根据专属服务地址重新构建双端。本包尚未实现可编辑服务器地址，也未创建任何朋友专属云端资源。不要把“建一个名为朋友的文件夹”当成已完成隔离。

## 7. 免费额度与轻量使用估算

截至 2026-10-02 查阅的官方额度如下。额度按账号合并使用，不能通过多建文件夹、Worker 或数据库获得重复免费额度。

| 服务 | 免费额度与关键限制 |
| --- | --- |
| Workers / Pages Functions | 每天 100,000 次请求；每次调用 CPU 10 ms |
| D1 | 每天读取 5,000,000 行、写入 100,000 行；账号总存储 5 GB；免费单库最大 500 MB，最多 10 个库 |
| R2 Standard | 每月 10 GB-month 存储、1,000,000 次 A 类操作、10,000,000 次 B 类操作；互联网出口流量免费 |

例如，两个人各有 2,000 张云端预览，平均每张 0.5 MB，总计约 2 GB；这只是图片体积估算，不是实际负载测试。还要考虑已有素材、预览版本、变更历史和其他服务用量。几个人轻量试用通常有希望在额度内，累计图片存储和大批量写入应持续观察。这里没有查询维护者账号当前用量，也不能保证永远免费。

D1 超过免费读写额度会暂时拒绝查询；R2 超出免费额度可能产生费用。维护者应在 Cloudflare 控制台关注 Worker 请求/CPU、D1 存储与读写、R2 总量与操作。R2 免费额度适用于 Standard，不适用于 Infrequent Access。

[Workers 价格](https://developers.cloudflare.com/workers/platform/pricing/) · [Workers 限制](https://developers.cloudflare.com/workers/platform/limits/) · [D1 价格](https://developers.cloudflare.com/d1/platform/pricing/) · [D1 限制](https://developers.cloudflare.com/d1/platform/limits/) · [R2 价格](https://developers.cloudflare.com/r2/pricing/)

## 8. 维护者：独立服务配置要点

这部分是维护指引，普通体验者无需操作。本次打包没有执行资源创建、线上迁移或部署。

1. 从可选源码包取得 cloudflare 目录。参考 cloudflare/wrangler.example.toml，为独立服务设置新的 Worker 名称，创建新的 D1 和 R2，分别绑定为 DB、ASSETS；填写自己的数据库 ID 和桶名。不要复用维护者个人库的绑定。
2. 将 cloudflare/migrations 中的迁移按序应用到这个新 D1 数据库；用 Worker Secret 设置新的高强度随机 MORI_SYNC_TOKEN，保持 ALLOW_INSECURE_LOCAL 为 0。不要把密钥直接写在代码、普通 vars 或说明书中。
3. 部署 Worker。如采用 Pages 网关，修改 pages-gateway 的服务绑定，使 MORI_SYNC 指向新 Worker，再部署独立网关。客户端连接的是能够访问该 Worker 的 HTTPS 入口。
4. 当前重新构建接入时，需要统一更新 public/js/sync 下各同步入口的固定地址，以及 Windows sync_authenticated_request.rs 的允许来源、Android MainActivity.java 的允许主机。只改网页地址会被原生请求限制拒绝。
5. 构建两端并在干净测试库配对；先用一个相册、几张图和一个策划完成电脑上传、手机下载、手机调整、电脑接收，再扩大使用。独立资源不等于已经完成双端接入验证。

两三个人可以先用独立服务，免去第一阶段多用户权限改造。若未来改成同一服务里的多个空间，需要后台按不同密钥检查空间归属，覆盖项目目录、变更读写和图片接口，不能只在界面隐藏其他相册。

部署与工具的当前用法请参考 [Cloudflare Workers 入门](https://developers.cloudflare.com/workers/get-started/guide/)、[D1 迁移](https://developers.cloudflare.com/d1/reference/migrations/) 和 [服务绑定](https://developers.cloudflare.com/workers/runtime-apis/bindings/service-bindings/)。

## 9. 问题反馈与源码

下载失败先确认链接有效、网络正常、保存目录可写；可以试另一条解析线路。不同平台的解析可用性会随网站变化。本次打包没有逐平台联网下载验收。

同步图片不齐先看状态里的失败原因并重试；不要立即清数据、卸载或重建。如果需要反馈，请记录平台、版本、操作步骤和错误提示，不发送自己的密钥或登录凭据。
